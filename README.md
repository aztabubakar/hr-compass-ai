# HR Compass AI

Starter repository for the Quantic **AI Engineering Techniques and Architectures** project.

The intended product is an agentic HR assistant that combines:
- policy Retrieval-Augmented Generation (RAG),
- MCP tool integration,
- synthetic employee/PTO/benefits data,
- multi-step HR workflows,
- grounded citations,
- concise operational tool traces,
- a web chat interface,
- automated tests/evaluation,
- CI/CD and free-tier deployment.

## Start here
Claude Code should read these files before implementation:
1. `PROJECT_SPEC.md` — authoritative project requirements extracted from the assignment.
2. `CLAUDE.md` — implementation instructions and constraints.
3. `docs/architecture.md` — proposed architecture and behavior.
4. `docs/acceptance-checklist.md` — definition of done.

## Important
All employee and HR operational data in this repository must be synthetic. Never commit API keys or secrets. Use environment variables and provide `.env.example`.
