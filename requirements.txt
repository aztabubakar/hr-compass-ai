# HR Compass AI dependencies. Install with: pip install -r requirements.txt
# Versions are pinned (via `pip freeze`) for reproducible, free-tier-friendly installs.
#
# Dependency strategy (see design-and-evaluation.md "Dependency Strategy" for full rationale):
# - numpy / faiss-cpu: vector math + a small local, persisted vector index (no server process).
# - fastembed: local, zero-cost text embeddings via ONNX Runtime (CPU-only, no torch/CUDA).
#   We deliberately use fastembed instead of the `sentence-transformers` package named in
#   CLAUDE.md's "preferred stack" because pip's default `torch` wheel on Linux pulls the full
#   CUDA/nvidia dependency chain (observed: ~5.9GB installed) unless a special CPU-only package
#   index is used. fastembed serves the SAME model referenced in .env.example
#   (sentence-transformers/all-MiniLM-L6-v2) as a small int8-quantized ONNX export, giving
#   equivalent 384-dim embeddings with a CPU-only, small install footprint — materially more
#   reliable for a free-tier host (e.g. Render's 512MB RAM tier). Documented deviation, permitted
#   by CLAUDE.md ("do not blindly follow these preferences if package/runtime compatibility
#   makes another free-tier-friendly design materially more reliable").
# - beautifulsoup4 / lxml: HTML policy document parsing.
# - pypdf: PDF policy document text extraction.
# - fpdf2: generates the synthetic PDF policy documents for the corpus (build-time only).
# - python-dotenv: loads .env for local configuration.
# - pydantic: typed, validated config, synthetic-data, agent I/O, and API models.
# - pytest: automated tests.
# - mcp: the official Model Context Protocol Python SDK. Used for both the MCP server
#   (mcp_server/, `mcp.server.mcpserver.MCPServer`) and the MCP client (mcp_client/,
#   `mcp.ClientSession` + `mcp.client.stdio`) over stdio transport. Pulls in a small ASGI stack
#   (starlette/uvicorn/sse-starlette) that the SDK itself needs for its HTTP/SSE transports,
#   which this project does not use (stdio only) but does not attempt to strip out, since it
#   adds only a small amount and keeps the dependency install exactly what `pip install mcp` gives.
# - anyio: structured-concurrency runtime used directly by the MCP client/server and agent
#   orchestrator code (`anyio.run(...)`), and transitively required by `mcp` and `fastembed`.
# - openai: the official OpenAI Python SDK, used as a thin, OpenAI-compatible HTTP client for
#   Groq (an alternative LLM provider -- see llm/groq_provider.py) rather than a Groq-specific
#   SDK. Groq (and most other free/low-cost inference providers) expose an OpenAI-compatible
#   chat completions API, so this same client, pointed at a different `base_url`, is the
#   natural way to add another provider later (see llm/groq_provider.py's module docstring).
# - google-genai: Google's current, actively-maintained Gemini Python SDK (not the older,
#   deprecated `google-generativeai` package), used by llm/gemini_provider.py -- this
#   project's primary/default LLM provider. Brings in google-auth (credential handling,
#   unused when authenticating by API key but part of the SDK's dependency surface),
#   pyasn1/pyasn1-modules (transitive, via google-auth's certificate parsing), distro (OS
#   identification for the SDK's User-Agent header), and tenacity (used internally by the
#   SDK's own HTTP layer; NOT what implements this project's retry policy -- see
#   llm/gemini_provider.py's module docstring on why the SDK's own retries are explicitly
#   disabled and a small bounded retry is implemented at the provider level instead).
# - httpx: promoted here from the "transitive, do not import directly" section below --
#   google-genai's async transport is httpx-based, and llm/gemini_provider.py imports it
#   directly to catch `httpx.TimeoutException`/`ConnectError`/`NetworkError` for
#   network-level failures the SDK's own `google.genai.errors.APIError` hierarchy doesn't
#   cover (mirroring how llm/groq_provider.py catches `openai`'s equivalent exceptions).
# - fastapi / uvicorn[standard]: the web API (/health, /chat, /api/tools) and ASGI server.
